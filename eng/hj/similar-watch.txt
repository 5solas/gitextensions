# One topic per line:  name | regex | globs
#   name   : free text shown in the report.
#   regex  : .NET regex matched case-insensitively against each upstream commit's subject and body.
#            Fields are separated by " | " (pipe with spaces), so write alternations WITHOUT spaces: a|b.
#            Leave empty (or "-") to match by path only.
#   globs  : comma-separated repo paths. "**" = any depth, "*" = within one path segment.
#            Leave empty (or "-") to match by keyword only.
# A commit matches a topic when the regex matches OR any changed file matches a glob.
# Keyword matching is a hint, not a verdict: expect false positives and misses.
